   119→## Unresolved Issues / Risks
   120→1. **Memory constraint**: 4GB RAM sandbox - server survives ~3-4 API route calls before OOM. Each new route loads Prisma modules causing memory growth from ~100MB to OOM threshold. In production with 8GB+ RAM this would not be an issue.
   121→2. **WebSocket service**: Must be manually started (mini-services/siem-ws-service/)
   122→3. **OpenSearch/Prometheus integration**: APIs designed but not connected to real backends
   123→4. **Authentication**: Default admin user only, no real session system
   124→5. **Live data**: All real-time features use simulated/mock data
   125→6. **Compliance API**: Returns 1 framework instead of 4 - likely a data issue in the seed or query
